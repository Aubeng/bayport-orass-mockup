# Bayport ORASS Mockup

Interactive UI mockup for the Bayport ORASS proposal, by Intellite IT Solutions.

## Viewing it

`index.html` is fully self-contained — all styles, scripts and assets are inlined,
with no external dependencies and no network calls. Open it directly in any modern
browser, or serve the folder statically.

```bash
python -m http.server 8000   # then open http://localhost:8000
```

## Scope of this repository

This repository holds the mockup only. Proposal documents, financial statements,
CVs, certificates and other bid material are deliberately kept out of it — see
`.gitignore`.
